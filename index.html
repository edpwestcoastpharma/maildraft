WC Voice Draft

Speak in Outlook, and AI writes the mail for you as a draft. This page gives you the file to add it to Outlook.

  1. Download the Outlook file. It is made for this website address:
    Open this page from your hosted https:// address (Vercel or Netlify), not from your computer.
  2. Add it to Outlook. Open outlook.office.com → open any mail → Apps (or ⋯ → Get Add-ins) → My add-ins → Add a custom add-in → Add from file → choose manifest.xml.
  3. Add your free API key. Get one at console.groq.com → API Keys. Then open any mail → WC Voice Draft → ⚙ → AI service: Groq (free) → paste the key → Save. Leave Signature empty if Outlook already adds yours.
  4. Use it. In a new mail, reply, or any received mail, click Voice Draft, tap the capsule, speak, tap again. The draft appears. Check it and press Send.

The add-in shows up in Outlook on the web, new Outlook for Windows and classic Outlook (same account) after a few minutes.
